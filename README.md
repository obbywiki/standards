# OW (Technical) Standards

This repository contains helpful standards that may or may not apply to work related to the Obby Wiki. It also contains some useful information such as [BRANDING.md](./BRANDING.md) and [PROJECTS.md](./PROJECTS.md). The standards repository is a good reference point if you want to start or request a new porject, and may also be helpful for projects unrelated to the OW.
